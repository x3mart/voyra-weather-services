# tiles-service

XYZ PNG-тайлы погодных слоёв для растрового слоя Mapbox (Flutter, voyra_app).

    uvicorn main:app --host 0.0.0.0 --port 8000
    GET /tiles/{layer}/{z}/{x}/{y}.png

| layer       | источник    | поле      | что рисует                  |
|-------------|-------------|-----------|-----------------------------|
| swh         | wave        | swh       | высота волны, м (заливка)   |
| perpw       | wave        | perpw     | период волны, с (заливка)   |
| wave_dir    | wave        | dir_u/v   | стрелки направления волн    |
| wind        | wind        | speed     | скорость ветра, м/с         |
| temperature | temperature | t2m       | температура 2 м, °C         |
| pressure    | pressure    | prmsl     | давление на уровне моря, гПа|

## Как это устроено

* **Источник** (`SOURCES` в `app/config.py`) — один npz из data-service со своей моделью сетки.
  **Слой** (`LAYER_CONFIG`) — то, что запрашивается в URL; один источник может питать несколько слоёв.
* `GridStore` хранит по источнику неизменяемый `Entry` (сетка + производные поля + версия) и
  подменяет его целиком, поэтому запрос во время перезагрузки видит данные одного цикла.
* Версия кэша тайлов = `cycle_date-cycle`, считается по источнику слоя.
* Поллер раз в 20 минут сверяет `current_cycle.json` с загруженными сетками; каждый источник
  обновляется независимо.
* Глобальная сетка при загрузке замыкается по долготе (лишний столбец = первый), иначе на высоких
  зумах на 180° появляется прозрачная полоса.

## Новый слой

* Новое поле в существующем источнике — запись в `LAYER_CONFIG` (и функция в `DERIVED_FIELDS`,
  если поле производное, как скорость ветра).
* Новый источник — класс сетки в `app/models.py`, запись в `SOURCES`, затем запись в `LAYER_CONFIG`.

## Что настроить под своё окружение

* `DATA_DIR` и имена файлов в `SOURCES` (`wavegrid.npz`, `windgrid.npz`, `temperaturegrid.npz`,
  `pressuregrid.npz`) — должны совпадать с тем, что пишет data-service.
* Имена полей в npz должны совпадать с полями моделей (`t2m`, `prmsl`, `u`, `v`, ...).
* Палитры температуры и давления — заготовки.
